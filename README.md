# Визуализатор зависимостей npm

Учебный CLI-проект для варианта 25 по дисциплине «Конфигурационное управление» (РТУ МИРЭА, 2026). Программа получает метаданные npm непосредственно из HTTP-реестра, строит граф обходом BFS без рекурсии, находит обратные зависимости и выводит диаграмму D2. Для получения сведений о пакетах не используются npm-команды и сторонние библиотеки.

## Требования

Node.js 18 или новее. Внешние npm-зависимости отсутствуют.

## Настройки

Все параметры задаются опциями командной строки:

| Опция | Значение | По умолчанию |
| --- | --- | --- |
| `--package` | Имя пакета, обязательно в онлайн-режиме | — |
| `--registry` | URL реестра npm | `https://registry.npmjs.org` |
| `--test-mode` | Чтение локального JSON-графа (`true`/`false`) | `false` |
| `--repo-file` | Путь к JSON-графу для тестового режима | — |
| `--version` | Версия пакета или `latest` | `latest` |
| `--max-depth` | Максимальная глубина (0 означает только корень) | `3` |
| `--reverse` | Показать обратные зависимости (`true`/`false`) | `false` |
| `--d2` | Вывести описание диаграммы D2 (`true`/`false`) | `true` |

При запуске все параметры печатаются в формате «ключ: значение». Для каждой опции проверяются наличие значения и корректность формата. В тестовом режиме проверяется JSON, наличие корневого пакета и структура списка зависимостей. Ошибки выводятся в stderr, программа завершается с кодом 1.

## Запуск

```sh
./run.sh --package express --version 4.21.2 --max-depth 2
```

Пример с локальным графом:

```sh
./run.sh --test-mode true --repo-file examples/graph-cycle.json \
  --package A --max-depth 5 --reverse true
```

Для обычного запуска требуются доступ к сети и доступность npm registry. Программа запрашивает JSON метаданные пакета, выбирает указанную версию и извлекает только обычные runtime-зависимости (`dependencies`). Опциональные и peer-зависимости не входят в граф, так как их установка зависит от среды и конфигурации. Версии зависимостей закрепляются по `dist-tags.latest`/выбранной версии конкретного пакета. Версионные диапазоны удовлетворяются выбором `latest` соответствующей зависимости, поэтому итог может отличаться от разрешения npm для конкретного lock-файла.

## Формат тестового репозитория

JSON-объект отображает имена пакетов на массивы их зависимостей:

```json
{
  "A": ["B", "C"],
  "B": ["D"],
  "C": ["D"],
  "D": []
}
```

Пакеты в примерах названы заглавными латинскими буквами по условию задания. Циклы разрешены. Неописанная зависимость трактуется как пакет без известных зависимостей.

## Вывод и обратные зависимости

Программа всегда выводит прямые зависимости корневого пакета, затем ребра найденного графа. `--reverse true` дополнительно печатает пакеты из построенного подграфа, у которых есть путь к выбранному пакету. В обратные связи включаются только пакеты, достижимые в пределах указанной глубины. Циклическое попадание корня в список исключается.

При `--d2 true` на экран печатается исходный текст диаграммы D2. Для отображения его можно передать установленному отдельно рендереру D2; рендерер не используется приложением для получения зависимостей. Граф задаёт направление `пакет -> зависимость`.

## Примеры трёх демонстраций

Все команды ниже работают автономно с примерами из `examples/`:

```sh
./run.sh --test-mode true --repo-file examples/graph-linear.json --package A --max-depth 8
./run.sh --test-mode true --repo-file examples/graph-diamond.json --package A --max-depth 8
./run.sh --test-mode true --repo-file examples/graph-cycle.json --package A --max-depth 8 --reverse true
```

Линейный граф показывает цепочку, ромбовидный — общую транзитивную зависимость, циклический — завершение обхода без повторной обработки узлов.

## Сравнение с npm

Для независимого сравнения используйте штатный вывод дерева npm в чистом временном проекте: `npm ls --all --json`. Для сравнения задайте тот же пакет и версию. У данного учебного инструмента граф строится из метаданных реестра и выбирает latest для каждой транзитивной зависимости; `npm ls` отражает фактически установленное дерево и ограничения проекта/lock-файла. Поэтому версии, опциональные зависимости, peer-зависимости и платформенные ветви могут расходиться. В тестовом режиме сравнение с `npm ls` неприменимо: граф задан искусственным JSON.

## Структура

- `src/` — CLI, загрузчик метаданных, обход графа, формирование D2.
- `tests/` — автоматизированные проверки разбора аргументов и графовых случаев.
- `examples/` — демонстрационные графы.
- `run.sh` — скрипт запуска.

Сборка не нужна. Запуск проверок: `npm test`.
